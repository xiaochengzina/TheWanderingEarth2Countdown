# 流浪地球 2 · 桌面倒计时

一个极简的《流浪地球 2》风格桌面倒计时，配一个深色 + 红主题的控制面板。

**当前版本：1.2.0**

---

## 一、安装

1. 把 `TheWanderingEarth2Countdown` 整个文件夹放进
   `文档\Rainmeter\Skins\`，最终路径是
   `文档\Rainmeter\Skins\TheWanderingEarth2Countdown\`。
2. 右键 Rainmeter 托盘图标 → **管理** → 找到 `TheWanderingEarth2Countdown`
   → 双击 `CountDown.ini`。
3. 在皮肤上**右键 → 打开控制面板**，就能改文字、目标时间、大小和配色。

> 皮肤会从 `@Resources\Fonts` 里自动加载字体，**不需要安装到系统**。
> 从 GitHub clone 的话这个文件夹是空的，按里面的 `字体说明.txt` 放字体进去即可
> （不装也能跑，只是会退回到系统默认字体，排版会跟设计稿有出入）。

如果图标被拖到屏幕外看不见了，右键托盘图标 → 管理 → 选中本项目 →
**移动** 一下就会回到屏幕里。

## 二、控制面板

面板是 `Settings\Settings.ini`，深色 + 红配色，共三页：

| 页 | 内容 |
| --- | --- |
| **内容** | 中文标题、英文标题、目标时间（年 / 月 / 日 / 时 / 分 / 秒）、实时预览 |
| **外观** | 整体缩放 40%–200%、强调色、正文色（点色块用取色器挑色） |
| **单位** | 自定义「什么时候换成更小的单位」的三个条件 |
| **高级** | 打开皮肤文件夹、恢复默认设置、关于信息 |

**操作方式**

- **输入框**：点一下弹出，回车确认、Esc 取消。清空后回车 = 设为「循环」。
- **目标时间的六个字段**：用 `−` / `+` 步进，或者直接点数字框输入。

  | 字段 | 步进规则 |
  | --- | --- |
  | 月 / 日 / 时 / 分 | 在「循环」和数值之间绕圈走 |
  | 年 | 只走 ±1；想设成「每年循环」请把输入框清空后回车 |
  | 秒 | 走 0–59，不支持留空 |

- **滑块**：按住拖动定位，滚轮微调，两侧 `−` / `+` 按钮粗调。
- **颜色**：点「外观」页右上角的小色块 → 弹出取色器 → 选完颜色**立刻生效**，
  面板和皮肤会一起变色，不用手动刷新。
  色块右边显示当前颜色的十六进制值，鼠标悬停可以看到 RGB。
- 面板右下角那道红色竖线是主皮肤的分隔条，不是面板的一部分 🙂

面板的改动**即时生效**，不需要刷新皮肤。设置会写回
`@Resources\Configs\Variables.inc`。

## 三、倒计时规则

### 目标是「模式」，不是某一个时刻

年 / 月 / 日 / 时 / 分 每一项都可以**留空**，留空表示「该项任意」。
皮肤每秒重新求一次「最近的下一个匹配时刻」：

- **六项全填** → 只有一个匹配时刻，过了就不会再有下一次 → 画面停在 `0 秒`。
- **任意一项留空** → 下一次永远存在 → 到点后自动开始下一轮。

| 留空 | 效果 |
| --- | --- |
| 年 | 每年 `月-日 时:分:秒`，例如每年 10 月 29 日 16:30:00 |
| 年 + 月 | 每月 `日 时:分:秒` |
| 年 + 月 + 日 | 每天 `时:分:秒` |
| …再加时 | 每小时 `分:秒` |
| …再加时、分 | 每分钟 `秒` |
| 都不留空 | 只触发一次，停在 `0 秒` |

> 判断依据是「**最小的那个留空字段**」。
> 例如年和月都留空，周期就是「月」而不是「年」。

### 留空怎么写

| 字段 | 留空方式 |
| --- | --- |
| 年 / 月 / 日 | 清空输入框，**或者填 `0`**（0 年 0 月 0 日本来就不合法） |
| 时 / 分 | **必须清空输入框**；填 `0` 表示「0 点 / 0 分」 |
| 秒 | 不支持留空，空着按 `0` 算 |

### 单位会自动切换

数字的单位随剩余时间自动变化，**最大单位是天**：

| 剩余时间 | 单位 | 数值 |
| --- | --- | --- |
| ≥ 第一个阈值（默认 72 小时） | 天 | 向下取整 |
| ≥ 第二个阈值（默认 120 分钟） | 时 | 向下取整 |
| ≥ 第三个阈值（默认 90 秒） | 分 | 向下取整 |
| 都不满足 | 秒 | 向下取整 |

三个阈值**可以在控制面板的「单位」页自己调**，页面底部有实时示例，
能立刻看到「剩余 100 天 / 10 小时 / 100 分钟 / 30 秒」分别会显示成什么。

因为取值是向下取整，阈值边界上会看到 `3 天 → 71 时`、`2 时 → 119 分`、
`1 分 → 89 秒` 这样的跳变，这是刻意设计。

> 阈值有下限，是为了避免出现「0 天」这种显示：
> 天不能小于 24 小时（否则剩余 20 小时时会显示 0 天）、
> 时不能小于 60 分钟、分不能小于 60 秒。

中文单位是「天 / 小时 / 分钟 / 秒」，英文会自动单复数
（`IN 1 DAY` / `IN 71 HOURS`）。

> 单位变化会让数字位数变化（`18725 天` → `71 时` → `89 秒`），
> 窗口宽度会跟着收放 —— 正常现象。

## 四、设置项

设置都存在 `@Resources\Configs\Variables.inc`，也可以直接改文件
（改完在皮肤上右键 → 刷新皮肤）。

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `CnText` | `距太阳氦闪` | 中文主标题（写长了会把右边整块往右推，见下） |
| `EnText` | `THE SOLAR HELIUM FLASH` | 英文主标题 |
| `TargetYear` | `2078` | 目标年，**留空 / 0 = 每年循环** |
| `TargetMonth` | `1` | 目标月，**留空 / 0 = 每月循环** |
| `TargetDay` | `1` | 目标日，**留空 / 0 = 每日循环** |
| `TargetHour` | `0` | 目标时，**留空 = 每小时循环**（`0` 是 0 点） |
| `TargetMinute` | `0` | 目标分，**留空 = 每分钟循环**（`0` 是 0 分） |
| `TargetSecond` | `0` | 目标秒，不支持留空（空按 `0`） |
| `UnitSwitchDay` | `72` | 剩余不足这么多**小时**就改用「时」（24–8760） |
| `UnitSwitchHour` | `120` | 剩余不足这么多**分钟**就改用「分」（60–10080） |
| `UnitSwitchMinute` | `90` | 剩余不足这么多**秒**就改用「秒」（60–3600） |
| `ColorAccent` | `234,10,3` | 强调色：红色竖条 + 大号数字 |
| `ColorText` | `227,231,229` | 正文色：中文标题 + 英文两行 |
| `Scale` / `ScalePercent` | `1.00` / `100` | 整体缩放，面板会同时维护这两个键 |
| `SettingsPage` | `1` | 面板上次停留的页码，自动维护 |

字号、间距、红条位置、单位文字、单位切换阈值这些**布局常量**在
`@Resources\Configs\Layout.inc` 里，每一项都有中文注释。
改之前建议先备份这个文件。

## 五、文件结构

```
TheWanderingEarth2Countdown\
├─ CountDown.ini               主皮肤
├─ README.md                   本文件
├─ Settings\
│  └─ Settings.ini             控制面板
└─ @Resources\
   ├─ Configs\
   │  ├─ Layout.inc            布局常量（字号 / 间距 / 单位文字 / 切换阈值）
   │  ├─ Variables.inc         你的设置，面板自动写入
   │  └─ Default.inc           出厂默认值（「恢复默认」用）
   ├─ Scripts\                 皮肤逻辑脚本
   ├─ Addons\
   │  └─ RainRGB4.exe          取色器（点色块时调用）
   └─ Fonts\                   自带字体
```

## 六、常见问题

**Q：皮肤一片空白，或者中文显示成「璺濆お闃虫唉闂」。**

A：文件编码被改坏了。用编辑器把 `CountDown.ini` 和 `@Resources\Configs\` 下的
`.inc` 重新另存为 **UTF-16 LE（带 BOM）**，并且保证**文件第一行是注释**，
不能直接以 `[Variables]` 开头。
（VS Code：右下角编码 → Save with Encoding → UTF-16 LE）

**Q：改了字号以后数字被切掉一半。**

A：`Layout.inc` 里的 `DaysFontSize` 和 `DaysY` 必须一起改，
两者大致满足 `DaysY ≈ 20 − 0.296 × DaysFontSize`。

**Q：天数怎么比我手算的少 1？**

A：数值是**向下取整**的（`floor`），不是「不足一天算一天」。

**Q：拖动皮肤时只有文字上能拖，空白处点不动。**

A：Rainmeter 皮肤是分层窗口，**完全透明（alpha = 0）的像素不接收鼠标**，
所以只有文字笔画能拖。主皮肤上加了一层「看不见但 alpha = 1」的
`MeterDragLayer`，给 7 个可见元素（中文标题、还剩、红条、大号数字、
单位、英文两行）**各盖一块矩形**。

现在在文字、红条、大号数字上都能按住拖动；
元素与元素之间的空白、以及画布四周的留白会**穿透到桌面**，不会误抓皮肤。

**Q：面板里改了设置，主皮肤没反应。**

A：面板靠配置名 `TheWanderingEarth2Countdown` 找主皮肤，
确认皮肤文件夹没被改过名。

**Q：想换一款字体，布局要重排吗？**

A：`Layout.inc` 里的 `FontCn`（中文）、`FontEn`（英文两行）、
`FontDays`（大号数字）是分开的，可以只换其中一个。
DIN 1451 Mittelschrift 一系的字体度量都很接近，基本不用重排布局。

**Q：中文标题写长了会盖住大号数字吗？**

A：不会。设计稿的标题位刚好放得下 5 个中文字，超过之后
**红条、还剩、大号数字、英文两行会整体右移同样的距离**，
字号和它们之间的对齐关系完全不变，皮肤窗口自动加宽。
所以标题想写多长都行，代价是皮肤整体变宽。

**Q：怎么把整套设置还原？**

A：控制面板 → 高级 → 恢复默认设置。

**Q：在输入框里打英文双引号 `"`，为什么没反应？**

A：这是 Rainmeter 的限制 —— 输入框的内容是直接拼进「动作字符串」里执行的，
值里带 `"` 会破坏外层引号，于是这次输入被丢掉（日志里会留一行 ERRO）。
换成中文引号「」或者全角引号即可。**不会写坏配置文件，重输一次就行。**

**Q：把中英文标题框清空，为什么标题还在？**

A：标题框不接受空值（空标题会让皮肤看起来像坏了），所以清空后回车不会生效。
想改成别的文字，直接输入新内容即可；想彻底换掉，也可以手改
`@Resources\Configs\Variables.inc` 里的 `CnText` / `EnText`。
